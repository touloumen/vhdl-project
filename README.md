Η εργασία γίνεται ως απαλλακτική των εξετάσεων στο μάθημα ψηφιακά ηλεκτρονικά συστήματα. 
Η εργασία είναι ατομική και δημιουργήθηκε σε γλώσσα VHDL στο προγραμματιστικό περιβάλλον VIVADO. 
Το αποτέλεσμα της εργασίας είναι η εξοικείωση με το πρόγραμμα VIVADO και την γλώσσα VHDL με απλές ασκήσεις. 
Για κάθε άσκηση υπάρχει εισαγωγή, κύριο μέρος, ανάλυση και συμπέρασμα. 
Χρήσιμη γνώση υπάρχει σε διάφορα σάιτ στο ίντερνετ , στο YouTube  εννοείται στο βιβλίο και στις διαφάνειες του μαθήματος.(Αναφέρονται την βιβλιογραφία).
